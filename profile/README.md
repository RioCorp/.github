# Rio Dev Group

**Based in Illinois. Building for games since 2019.**

Rio Dev Group is a small, tight-knit team of developers focused on game security research and premium scripting solutions. What started in 2019 as a two-person project - a C++ Minecraft client built around JNI-based manipulation of the Java runtime - has grown into an ongoing body of work spanning multiple engines, languages, and client relationships.

---

## ❔ Our Collective Interests

1. Licensing systems: Building custom authentication flows protected by perfect cryptographic practices and client-server obscurities.
2. Anti-cheat analysis: Working with systems like VAC, Hyphon, Adonis, OpenAC, Rivals, and BAC.
3. Luau scripting: Creating enhancement scripts for popular Roblox.com experiences.
